# Rock Paper Scissors

A simple command-line implementation of the classic Rock Paper Scissors game, built as part of The Odin Project foundations course.

## How to Play

1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. Open your browser's developer tools console (`F12` or right-click -> Inspect -> Console).
4. A prompt will pop up asking you to enter `rock`, `paper`, or `scissors`.
5. Play through 5 rounds, and check the console to see the final winner and scores!

## Built With

- HTML5
- JavaScript (Vanilla)

## Project Structure

- `index.html` — The main entry point that links the JavaScript file.
- `script.js` — Contains all the game logic, functions, and loop.
- `styles.css` — Stylesheet (currently empty since the game runs in the console).
